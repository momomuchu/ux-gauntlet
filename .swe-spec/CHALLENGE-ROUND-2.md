## 4. Systemic observations

**§4.1 — Convergent finding as signal strength.** Two independent attacks in the feasibility lens (one framed as a literal-contradiction reproduction against the F61 test, one framed as an unimplementable/untested-requirement claim) landed on the identical root defect: N8's flag list omits `--env`, which F61 requires unconditionally. Independent convergence from different framings on the same file/line evidence is treated as higher-confidence than either attack alone — merged into one BLOCKER entry above rather than double-counted.

**§4.2 — Recurring class: decision landed, trace convention not honored.** Three separate confirmed findings (F118/F119 max-vs-mean severity, F109 schema enforcement, "Known verification gaps" undercount) share the same shape: a real design decision was made and is defensible on inspection, but spec.md's own stated documentation conventions (inline `CR1-NN` markers in the Decisions table, accurate wording in the gap-disclosure section) were not honored for that specific decision. This is a lower-severity, higher-frequency defect class than outright contradictions — worth a single sweep before the next freeze rather than one-off fixes.

**§4.3 — Recurring class: execution-model claims (parallelism, isolation) are asserted but not gated.** F30/F31/F32/F88 surfaced independently in two different confirmed findings (the N5 sequential-derivation contradiction, and the zero-coverage finding) — both point at the same underlying fact: the spec's single most prominent architecture claim (independent parallel persona subagents with isolated browser sessions) has no test-suite proof of concept, only a code comment asserting it will be "exercised empirically at build."

**§4.4 — Recurring fix pattern: per-step operator-override schema field.** Three confirmed BLOCKER/MAJOR findings (F40/F89 precondition steps, F37/F38 denylist override, F27 standardized-flow allowlist) each proposed the identical shape of fix: a new operator-set boolean/reference field scoped to a single task-list step, following the precedent already set by `payment_step` (F115) and `external_side_effect` (F62). Rather than adding three more one-off per-step flags, the underlying task-list schema may benefit from one generalized "operator override" extension point (name, scope, logging requirement) that F126/F127-style fixes could each register against, rather than three independently-numbered ad hoc booleans.

**§4.5 — Panel discipline held.** All 4 rejected attacks were dismissed only after direct file/line verification (F111-113's existing partition logic; F67/F68's literal "non-localhost" qualifier; D11's explicit CRITICAL classification; F121's actual gated axis) — none were dismissed on the reviewer's assertion alone. Several raw attacks claimed BLOCKER severity that was downgraded on evidence (e.g. F103, F27/F124, F26/convergence_tier, F109 all originally framed at MAJOR/BLOCKER but confirmed only at MINOR after checking whether the described failure actually reproduces against the frozen test suite) — the panel systematically discounts theatrical framing not backed by literal-text reproduction, consistent with round 1's calibration.
